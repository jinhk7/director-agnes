# 时间序列抽帧审片

用途：在视频生成后、剪辑前，用按时间排列的缩略图看清动作变化和生成瑕疵；针对异常加密取样，再作可解释的剪辑决定。也用于最终导出复核。本方法不限于某个模型，5.6-terra 或其他执行模型加载本文件并具备本地读图工具时均按同一流程执行；不保证不同模型判断完全一致。

## 最小执行路径

1. 读取项目分镜、已验收首帧、对应视频和当前版本。每镜明确剧情职责及预期的起点→动作→终态。先核对实际文件与shot_id，不能靠目录顺序猜镜号。
2. 为每段生成总览联系表：短片段从0秒开始每秒一帧，加上靠近尾端的一帧；每页最多12张，默认4列。长片分页，不把整片缩成一张无法辨认的图。每格标镜号和源时间，按从左到右、从上到下排列。
3. **实际调用读图工具打开每张联系表。** 生成图片文件、返回路径、ffmpeg成功都不算看过。逐镜记录看到了什么，先事实后判断。小物件看不清时提高单格分辨率或打开单帧，不凭缩略图猜测。
4. 对可疑区间加密：例如0–2秒每0.2秒一帧，必要时缩到每帧；保留异常前后，定位首次出错及可用入出点。总览没有捕捉到的动作记为不确定，不能直接判“没有发生”。快速动作和精确切点再用播放器或逐帧查看确认。
5. 同时审查相邻镜尾与下一镜头：外观、道具、站位、屏幕方向、场景及因果是否衔接。对照实际首帧，识别视频自行添加的背景或角色。
6. 基于证据选保留、修剪、裁剪、弃用或补生成，写入剪辑清单。使用保留区间完成剪辑后，对导出成片再次抽帧，检查切点两侧，再在实际播放器确认画面与播放进度。所有对白段单独试听，检查断字与声画同步。

## 逐镜看什么

|维度|判断依据|
|---|---|
|动作|能看见正确起点、中间变化、终态；是否复位、瞬移、提前完成、重复表演或停顿过长|
|身份与数量|头脸、身体比例、服饰是否保持；是否出现多余角色、肢体或独立倒影角色|
|道具|唯一数量、握持/戴取顺序、接触前间隙、落点与方向；避免凭空出现、穿模或提前拾取|
|场景|是否无来源新增棚架、植物、建筑或改变地形；灯光和画风是否突变|
|状态连续性|污迹/伤痕/服装变化是否有动作原因；是否下一镜消失或从表面污迹变为天然毛色|
|倒影|是否与本体位置和运动同步，是否呈物理反射；不能接受水下站着的第二个主体|
|叙事|每镜是否提供必要因果；删去后观众还能否理解后续行为及揭晓|

## 剪辑决策与边界

- **保留**：动作和叙事可用，记录来源区间。可剪去纯等待、动作后多余停留，但保留必要反应与台词尾音。
- **修剪**：缺陷只出现在部分时间，切掉后仍能表达完整职责。不能截取任意“好看”片段忽略动作起终点。
- **裁剪**：错误仅在画面边缘，裁后主体、道具和动作仍完整。必须复查裁后的实际画面；原图可见不代表裁后可见。记录裁剪区域及清晰度损失。
- **弃用/省略剪辑**：相邻镜能合理传达被省略动作时可用；说明如何衔接。关键证据被删（例如看到倒影才误认自己）就记录叙事缺口，不能声称完整保留因果。
- **补生成**：缺陷破坏主要动作、身份或必要剧情，且无法局部修剪。回到对应首帧/提示词版本，在已授权范围重做；不无上限重复生成。

本次实例仅用于解释判断：总览发现棚架与额外角色；倒影异常后对开头加密抽帧，评估是否保留低头局部。最终弃镜与裁剪跑通了样片流程，但削弱了倒影揭晓证据。可复用的是观察与决策过程，不是固定删某个镜号。

## 可运行工具

`scripts/make_review_sheet.py` 依赖本地Python、Pillow和FFmpeg，并复用同目录render_edit.py的媒体检查函数。先检查现有运行环境；缺依赖时明确处理，不伪造结果。

```text
python scripts/make_review_sheet.py video/S07-v001.mp4 --shot-id S07 --ffmpeg /absolute/path/to/ffmpeg --output-dir reviews/S07-v001/overview
python scripts/make_review_sheet.py video/S07-v001.mp4 --shot-id S07 --start 0 --end 2 --step 0.2 --ffmpeg /absolute/path/to/ffmpeg --output-dir reviews/S07-v001/detail-00-02
```

输出原始单帧、带镜号/时间的分页联系表和review.json。单帧时间是请求的源时间位置，实际解码落在临近帧；它不是帧精确剪辑证据。原生帧率下的精确切点需进一步检查。输出目录非空时拒绝覆盖，另建审片版本。脚本不自动打分、不调用模型、不试听音频；review.json初始状态始终pending。

容器或音频时长可能略长于最后一帧。仅末次取样无图时，脚本最多向前尝试0.1秒、0.25秒，并记录原请求时间和实际使用的请求时间；联系表标注后者，不伪称取得了原时间点。中间缺帧仍报错，尾部回退与前一取样重叠时要求指定更早的 `--end`。

若没有此脚本所需运行环境，可用本地FFmpeg或可用编辑器取等效帧序列，但仍保留镜号、时间、阅读顺序、原图和证据记录。无法看图则记录needs_visual_review；缺试听能力则记录needs_audio_review，不把两者写为通过。

## 审核记录和交接

每个缺陷记录：shot_id、素材版本/路径/哈希、观察区间、证据图片路径、可见事实、对照预期、影响、建议处理、保留入出点/裁剪参数、复核状态及来源。人工填写 findings，不用脚本的元数据替代结论。

汇报示例：“S07，源时间0.8–1.8秒，水面角色直立且与本体不同步，疑似独立动物；已查看加密联系表。可试裁掉右侧，但会失去倒影揭晓证据，流程样片需披露，正式版建议补镜。”

分开记录 file_check、visual_review、action_review、continuity_review、dialogue_review、lip_sync_review、narrative_review 和 playback_review。视觉证据来源为assistant_visual；文件/解码为tool_check；实际试听为assistant_listening；用户反馈为user_report。抽帧不能证明语音内容、完整口型或中间所有帧无缺陷。

切换模型或新会话时，从production.json和reviews恢复：读取现有证据与结论，复用已完成审核，针对缺失项继续。不要依赖“上一位助手看过”而没有素材版本与证据路径的口头保证。
